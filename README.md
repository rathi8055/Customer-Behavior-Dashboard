# Customer Behavior Dashboard 📊

## Project Overview

The Customer Behavior Dashboard is an interactive data analytics project developed using Microsoft Power BI.

The dashboard provides insights into customer purchasing patterns, subscription status, sales performance, revenue distribution, and customer demographics.

It helps understand customer behavior through interactive visualizations and filters.

## Key Performance Indicators (KPIs)

The dashboard displays the following key metrics:

- **Number of Customers:** 49
- **Average Purchase Amount:** $52.06
- **Average Review Rating:** 3.78

## Dashboard Features

### 1. Customer Subscription Analysis
- Percentage of subscribed and non-subscribed customers.
- Subscription status comparison.

### 2. Revenue Analysis
- Revenue distribution by product category.
- Revenue comparison across different age groups.

### 3. Sales Analysis
- Sales performance by product category.
- Sales distribution across age groups.

### 4. Interactive Filters
The dashboard includes filters for:
- Subscription Status
- Gender
- Product Category
- Shipping Type

These filters allow users to explore customer behavior based on different criteria.

## How to Use

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file.
4. Explore the dashboard and interact with the available filters.
